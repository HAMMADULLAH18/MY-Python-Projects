## 💻 Run a Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/HAMMADULLAH18/MY-Python-Projects.git
```

### 2. Open the project directory

```bash
cd MY-Python-Projects
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Launch an application

Run the desired project using its Streamlit entry-point file:

```bash
python -m streamlit run atm_app.py
```

```bash
python -m streamlit run budget_app.py
```

```bash
python -m streamlit run marks_app.py
```

*Note: These commands assume the corresponding application files exist in the repository root.*
